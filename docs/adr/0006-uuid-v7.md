# ADR-0006 — Identificadores UUID v7

- Status: aceita
- Data: 2026-11-03

## Contexto

Entrevistas, respostas e mídias nascem no aparelho, sem internet. O ID precisa ser único sem consultar o servidor e permitir reenvio sem duplicar (idempotência).

## Decisão

- Todas as chaves primárias são UUID v7.
- Registros criados offline recebem o ID no aparelho; o servidor aceita esse ID.

## Consequências

- UUID v7 é ordenado no tempo, o que mantém índices eficientes.
- Reenviar uma entrevista com o mesmo ID não cria registro novo.
